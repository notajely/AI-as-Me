# 02_Styles - 风格与习惯层

> **定义**: 稳定的工作习惯、沟通风格、工具偏好和操作流程。

## 特征

- **生命周期**: 中期（3-12个月）
- **可操作性**: 直接影响 AI 的行为模式
- **可配置**: 支持 YAML/JSON 格式化配置

## 沉淀机制

### 输入源
- `01_Timeline` 中出现 ≥3 次的模式
- 明确声明的工作偏好
- 工具使用习惯
- 沟通风格分析

### 升级至 03_Mindset
当某个风格被长期稳定使用（≥6个月）且具有普适性时，升级至 `03_Mindset`

### 修正
允许人工或 AI 建议修正不再适用的习惯

## 配置文件说明

### communication.yaml
定义沟通风格偏好：
- 语气、语调
- 回复长度
- 表情符号使用
- 专业术语偏好

### work_habits.yaml
定义工作习惯：
- 任务分解方式
- 文档详细程度
- 代码风格偏好
- 时间管理模式

### tools.yaml
定义工具偏好：
- 编辑器选择
- 终端偏好
- 版本控制习惯
- 常用命令

## 使用方式

AI 助手会在工作时参考这些配置：
- 根据 `communication.yaml` 调整回复风格
- 根据 `work_habits.yaml` 组织任务
- 根据 `tools.yaml` 推荐工具和命令

## 维护建议

- 每月审查 AI 建议的 `01 → 02` 升级
- 及时修正不再适用的习惯
- 记录习惯的稳定时间（用于判断是否升级至 `03_Mindset`）
