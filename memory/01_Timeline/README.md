# 01_Timeline - 时间线记忆

> **定义**: 近期事件、对话摘要、项目进展的时序记录。

## 特征

- **生命周期**: 近期（1-3个月）
- **按时间组织**: 年/月/日分类
- **可检索性**: 通过时间、主题检索

## 目录结构

```
01_Timeline/
├── 2026/
│   ├── 01-January/
│   │   ├── 2026-01-01.md
│   │   └── 2026-01-15.md
│   └── 02-February/
└── archive/
    └── 2025/
```

## 沉淀机制

### 输入源
- `00_Current` 的会话摘要
- 项目里程碑记录
- 重要事件标记
- 日常互动记录

### 升级至 02_Styles
当某个模式/习惯在 `01_Timeline` 中出现 **3次或以上** 时，自动提示升级至 `02_Styles`

### 归档
超过 3 个月的记录可归档至 `archive/` 目录

## 记录模板

每条时间线记录应包含：
- 日期时间
- 事件摘要
- 关键决策
- 发现的模式
- 待跟进事项

## 模式识别

AI 助手会自动检测重复出现的模式：
- 工作习惯（如每天早上先处理邮件）
- 沟通风格（如偏好简洁回复）
- 决策模式（如优先考虑长期影响）

当模式出现 ≥3 次时，建议升级至 `02_Styles`

## 维护建议

- 每周审查新增记录
- 每月检查可升级的模式
- 每季度归档旧记录
