# 00_Current - 当前工作记忆

> **定义**: 当前会话的临时工作空间，存储即时任务数据和活跃上下文。

## 特征

- **生命周期**: 单次会话或临时任务
- **易失性**: 会话结束后需要提炼或丢弃
- **容量**: 不限，但应定期清理

## 使用方式

### 会话记录
- 创建 `session_[日期].md` 记录当前会话
- 会话结束后提炼至 `01_Timeline`

### 临时笔记
- 使用 `temp_notes.md` 存储临时想法
- 定期整理或删除

### 活跃任务
- 使用 `active_tasks.json` 跟踪待办事项
- 任务完成后移除

## 沉淀流程

```
00_Current → 01_Timeline
触发条件:
- 会话结束
- 对话超过 10 轮
- 完成重大任务
```

## 维护建议

- 每日清理过时的临时文件
- 会话结束后及时提炼至 `01_Timeline`
- 避免长期积累未处理的内容
