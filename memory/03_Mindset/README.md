# 03_Mindset - 思维模型层

> **定义**: 思维模型、决策框架、知识结构和专业领域的抽象理解。

## 特征

- **生命周期**: 长期（1年以上）
- **抽象性**: 超越具体事件的通用原则
- **结构化**: 形成知识图谱

## 沉淀机制

### 输入源
- `02_Styles` 中稳定且普适的习惯
- 明确表达的思维框架
- 专业领域的知识沉淀
- 决策树和推理模型

### 升级至 04_Identity
**升级条件**:
- `02_Styles` 中的某个记忆稳定运行 ≥6 个月
- 具有跨场景适用性
- 需要与 `04_Identity` 一致性校验
- **必须人工确认**

### 修正
允许基于新认知进行迭代更新

## 核心文件说明

### decision_frameworks.yaml
定义决策框架和思维模型：
- 问题解决流程
- 优先级判断矩阵
- 风险评估框架
- 创新思维模式

### knowledge_domains.yaml
定义专业知识领域：
- 专业领域列表
- 技能树结构
- 学习路径
- 核心概念网络

### thinking_patterns.md
定义思维习惯和认知模式：
- 学习方式
- 信息处理偏好
- 认知偏好
- 元认知策略

## 使用方式

AI 助手会在以下场景参考这些模型：
- 需要做决策时，参考 `decision_frameworks.yaml`
- 讨论专业话题时，参考 `knowledge_domains.yaml`
- 解释你的思考方式时，参考 `thinking_patterns.md`

## 维护建议

- 每季度审查 `02 → 03` 升级建议
- 随着认知更新而迭代
- 记录思维模型的演变历程
- 定期与 `04_Identity` 进行一致性检查
